# One-off scripts from past site migrations

Kept for the record; **a new install never runs any of these**, and they are not maintained.
They were written for one site at one moment (kernel 0.1.7 cut-over, seat collapse, roster
landing, workspace fixes in September–October 2026) and assume they sit in `server/` next to
the scripts they call, with that site's paths. What a server runs is `scripts/setup-all.ps1`
and the scripts it calls; what an admin runs afterwards is listed in
[docs/SERVER.md](../../docs/SERVER.md) and [ARCHITECTURE.md](../../ARCHITECTURE.md).
